# dmenu
Triet's version of suckless dmenu. It shows search bar which search for programs to be run. This is similar to clicking on window icon in Window OS and typing in the program you want to run. Triet uses this together with dwm and slstatus to replace a regular Desktop Environment.

Source code: https://tools.suckless.org/dmenu/

## Current feature
1. Menu shows up in the middle of screen
2. Border around menu
3. Search is fuzzy
4. Search is fuzzy hilighted

## Download
```
git clone https://github.com/triet228/dmenu.git
```
## Installtion
Go to cloned directory
```
cd dmenu
``` 
Install
```
sudo make clean install
```
Uninstall
```
sudo make uninstall
```

## Run dmenu
Temporary run in terminal ```dmenu_run```

Typical use ```Alt + p```

Escape dmenu ```Esc```
